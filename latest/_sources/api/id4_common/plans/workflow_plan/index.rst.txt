.. py:function:: run_workflow(bluesky_id=None, dm_concise: bool = False, dm_wait: bool = False, dm_reporting_period: float = 10 * 60, dm_reporting_time_limit: float = 10**6, settings_file_path: str = None, **_kwargs)

   Submit a DM workflow plan and optionally share Bluesky run metadata with DM.

   :param bluesky_id: Scan whose metadata is shared with DM. A str or int is looked up in
                      the catalog and raises a KeyError if not found; a BlueskyRun is used
                      directly. Anything else (including the default None) logs a warning
                      and skips the metadata upload.
   :type bluesky_id: str, int or BlueskyRun, optional
   :param dm_concise: Use concise reporting in the DM workflow. Defaults to False.
   :type dm_concise: boolean, optional
   :param dm_wait: If True, wait for the workflow job to finish before continuing.
                   Defaults to False.
   :type dm_wait: boolean, optional
   :param dm_reporting_period: How often the DM workflow reports progress, in seconds. Defaults to
                               10 minutes.
   :type dm_reporting_period: float, optional
   :param dm_reporting_time_limit: How long bluesky keeps reporting on the DM workflow, in seconds.
   :type dm_reporting_time_limit: float, optional
   :param settings_file_path: Path to a YAML file holding the workflow kwargs. Keyword arguments
                              given in the function call take priority over the file. Raises a
                              FileExistsError if the path does not exist.
   :type settings_file_path: str, optional
   :param \*\*_kwargs: Arguments passed to the DM workflow. The ``workflow`` key is required
                       and must be one of the keys of ``EXPECTED_KWARGS``; every entry that
                       ``EXPECTED_KWARGS[workflow]`` lists must be present, otherwise a
                       ValueError is raised. The strings "None" and "none" are converted to
                       None.
