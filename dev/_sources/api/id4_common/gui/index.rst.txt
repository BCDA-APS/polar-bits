id4_common.gui
==============

.. py:module:: id4_common.gui

.. autoapi-nested-parse::

   Qt desktop interface for the POLAR Bluesky session.

   This package is an *additive* front end: it starts a Jupyter kernel that runs
   the same ``from id4_common.startup import *`` bootstrap as the plain IPython
   session, so the existing command-line workflow is unaffected.

   Launch with the ``polar-gui`` console script.
